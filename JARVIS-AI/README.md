# JARVIS-AI

A modular full-stack AI assistant project built with Flask, MongoDB, Bootstrap, and OpenAI integration.

## Structure

- `backend/` contains the Flask API, database models, services, and utilities.
- `frontend/` contains the Bootstrap-based user interface and client-side JavaScript.
- `docs/` is reserved for product and technical documentation.

## Getting started

1. Create a Python virtual environment.
2. Install backend dependencies from `backend/requirements.txt`.
3. Configure the environment variables in `backend/.env`.
4. Start the Flask application from `backend/app.py`.
5. Open the frontend files in a browser or serve them through a static host.
